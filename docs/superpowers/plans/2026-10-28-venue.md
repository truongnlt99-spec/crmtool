# Venue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu Venue (venue + sản phẩm theo tone), ô Venue dự kiến trong lead, gợi ý venue từ lead, tool MCP venue.

**Architecture:** Logic thuần ở `web/venue.js` (`window.Venue`), UI ở khối `RENDER: VENUE` trong `index.html`.
Venue lưu ở `<kho>/venues`, tone thêm ở `<kho>/toneMau`. App **ghi venue/sản phẩm/tone thẳng** bằng
`update()` theo đường dẫn nhỏ nhất ngay khi bấm (không đi qua diff `tinhThayDoiCucBo`), state venue luôn
lấy lại từ snapshot máy chủ trong `applyRemoteData`. `lead.venueId` đi theo lead như các ô khác.

**Tech Stack:** HTML + JS thuần, Firebase RTDB, Vercel Function TS (`api/mcp.ts`), test Node chạy `.ts` + Chrome ngầm.

**Spec:** `docs/superpowers/specs/2026-10-28-venue-design.md`

## Global Constraints

- Không tách code ra ngoài `api/` cho MCP; mọi tool đọc/ghi qua `dataRoot()`.
- Ghi Firebase bằng PATCH/`update` theo đường dẫn nhỏ nhất; không PUT đè nhánh.
- Chỉ xem (`window.__chiXem`) → không ghi gì; ẩn nút sửa.
- Escape mọi chữ người dùng/Claude nhập; `link` chỉ nhận `^https?://`.
- Tone mặc định (CHÉP 2 NƠI `web/venue.js` + `api/mcp.ts`): Trắng, Xanh lá, Xanh dương, Hồng, Đỏ, Vàng/Champagne, Tím, Be/Nude, Pastel, Đen.
- `venueId` thêm vào `FIELD_WHITELIST` ở cả `web/ho-so-ai.js` và `api/mcp.ts`.
- Commit tiếng Việt không dấu.

## Review Focus

1. Claude thêm sản phẩm trong lúc Trân đang sửa venue đó → không mất sản phẩm nào (ghi theo `venues/<id>/sanPham/<spId>`).
2. Xoá venue đang gắn lead → các lead đó `venueId = null`, không còn trỏ venue ma; đề xuất venueId trỏ venue đã xoá thì Duyệt báo lỗi.
3. Seed chạy lại → không tạo venue trùng tên (so không dấu), không đè `venueId` đã có.
4. Bí danh lồng nhau ("white palace" trong "white palace pham van dong") → chỉ tính venue dài nhất.
5. Link `javascript:`/tên có HTML → bị từ chối / escape (test UI).

### Task 1: `web/venue.js` hàm thuần + test

**Files:** Create `web/venue.js`, `test/venue.test.ts`; Modify `package.json` (`test:venue`).

**Produces:**
- `TONE_MAC_DINH: {id, ten, mau}[]` (id: `trang, xanh-la, xanh-duong, hong, do, vang, tim, be, pastel, den`)
- `VENUE_MAU: {ten, bietDanh: string[]}[]` — rút từ dữ liệu thật
- `danhSachTone(toneMau): Tone[]` — mặc định + tone thêm (bỏ trùng id)
- `linkHopLe(s): boolean`
- `kiemTraSanPham({ten, link, gia, tone}, toneIds): string|null`
- `locSanPham(venues, { q, tone: string[], venueId }): {venue, sp}[]` — `tone` khớp bất kỳ; `q` không dấu trên tên venue + tên/giá sp; mới nhất trước
- `timVenueTheoTen(venues, ten): venue|null` — so không dấu, bằng nhau
- `khopVenueMau(leads, venues, mau=VENUE_MAU): { goiY: {ten, leadIds}[], canChonTay: {leadId, ten: string[]}[] }`
  — chữ dò = `schedule` + ghi chú + `baoGia.*.diaDiem`; khớp dài nhất; bỏ venue đã có; `leadIds` chỉ lead khớp đúng 1 venue và chưa có `venueId`
- `veSanPham(venue, sp, tones, { chiXem }): string` — HTML đã escape, có nút copy (`data-link`)
- `soLeadTheoVenue(leads): Record<venueId, number>`
